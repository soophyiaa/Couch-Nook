OBJETIVO DO GUIA

Antes de começar as fases de coreano, você precisa conhecer o Hangul, o sistema de escrita da língua coreana.

O Hangul é formado por consoantes e vogais que se juntam para formar blocos silábicos. Cada bloco representa uma sílaba.

O alfabeto moderno possui 14 consoantes básicas e 10 vogais básicas. Também existem consoantes aspiradas, consoantes tensas e vogais compostas.

1. COMO FUNCIONA O HANGUL?

Diferentemente do alfabeto português, as letras coreanas não são escritas apenas em sequência horizontal. Elas são organizadas em blocos silábicos.

ㅎ + ㅏ + ㄴ = 한

ㄱ + ㅜ + ㄱ = 국

한 + 국 = 한국

A palavra 한국 significa Coreia. Observe que cada bloco reúne consoantes e vogais em uma única unidade visual.

2. CONSOANTES BÁSICAS

As consoantes básicas são 14. Cada uma possui um som aproximado em português, mas a pronúncia pode mudar conforme sua posição na sílaba.

ㄱ — som entre G e K

ㄴ — N

ㄷ — som entre D e T

ㄹ — som entre R e L

ㅁ — M

ㅂ — som entre B e P

ㅅ — S

ㅇ — não possui som no início; NG no final

ㅈ — som próximo de J

ㅊ — CH aspirado

ㅋ — K aspirado

ㅌ — T aspirado

ㅍ — P aspirado

ㅎ — H aspirado

IMPORTANTE: as aproximações ajudam no início, mas os sons coreanos não correspondem perfeitamente aos sons do português.

3. CONSOANTES ASPIRADAS

As consoantes aspiradas são pronunciadas com uma saída de ar mais forte. São quatro letras principais:

ㅋ — K aspirado

ㅌ — T aspirado

ㅍ — P aspirado

ㅊ — CH aspirado

Compare:

ㄱ — som menos aspirado

ㅋ — som mais aspirado

ㄷ — som menos aspirado

ㅌ — som mais aspirado

ㅂ — som menos aspirado

ㅍ — som mais aspirado

Na pronúncia, o ar deve sair com mais força nas letras aspiradas.

4. CONSOANTES TENSAS

As consoantes tensas são produzidas com maior tensão muscular e sem a mesma explosão de ar das aspiradas.

ㄲ — versão tensa de ㄱ

ㄸ — versão tensa de ㄷ

ㅃ — versão tensa de ㅂ

ㅆ — versão tensa de ㅅ

ㅉ — versão tensa de ㅈ

Essas cinco letras são importantes porque podem diferenciar palavras.

5. VOGAIS BÁSICAS

O Hangul possui dez vogais básicas:

ㅏ — A

ㅑ — YA

ㅓ — EO

ㅕ — YEO

ㅗ — O

ㅛ — YO

ㅜ — U

ㅠ — YU

ㅡ — EU

ㅣ — I

Algumas pronúncias não existem exatamente em português. A vogal ㅓ, por exemplo, tem um som diferente do nosso O. Já ㅡ é pronunciada com os lábios sem arredondamento.

6. VOGAIS COMPOSTAS

As vogais compostas são formadas pela combinação de vogais simples.

ㅐ — AE

ㅒ — YAE

ㅔ — E

ㅖ — YE

ㅘ — WA

ㅙ — WAE

ㅚ — OE

ㅝ — WEO

ㅞ — WE

ㅟ — WI

ㅢ — UI

Exemplos de combinações:

ㅗ + ㅏ = ㅘ

ㅗ + ㅐ = ㅙ

ㅜ + ㅓ = ㅝ

ㅜ + ㅣ = ㅟ

7. COMO FORMAR SÍLABAS?

As letras são organizadas em blocos. Uma sílaba pode ter consoante e vogal ou consoante, vogal e consoante final.

가 = ㄱ + ㅏ

나 = ㄴ + ㅏ

고 = ㄱ + ㅗ

문 = ㅁ + ㅜ + ㄴ

한 = ㅎ + ㅏ + ㄴ

Quando a vogal é vertical, ela fica à direita da consoante.

ㄱ + ㅏ = 가

ㄴ + ㅣ = 니

Quando a vogal é horizontal, ela fica abaixo da consoante.

ㄱ + ㅗ = 고

ㄴ + ㅜ = 누

Quando existe uma consoante final, chamada 받침 (batchim), ela fica na parte inferior do bloco.

한 = ㅎ + ㅏ + ㄴ

밥 = ㅂ + ㅏ + ㅂ

8. ORDEM E DIREÇÃO DOS TRAÇOS

Para escrever corretamente, é importante respeitar a ordem dos traços de cada letra.

Regras gerais:

1. Escreva de cima para baixo.

2. Escreva da esquerda para a direita.

3. Faça primeiro os traços superiores e depois os inferiores, quando a letra exigir essa ordem.

4. Mantenha os traços organizados dentro do espaço da letra.

5. Pratique cada letra separadamente antes de formar sílabas.

Exemplos de ordem:

ㄱ: traço horizontal e depois traço vertical para baixo.

ㄴ: traço vertical e depois traço horizontal para a direita.

ㅏ: traço vertical e depois pequeno traço horizontal.

ㅗ: traço horizontal e depois pequeno traço vertical para cima.

ㅣ: um único traço vertical.

ㅡ: um único traço horizontal.

Essas são orientações iniciais. Algumas letras possuem ordens próprias, por isso é importante observar cada modelo de escrita.

9. PRIMEIRAS PALAVRAS

Agora que você conhece as letras, observe algumas palavras formadas por blocos silábicos.

안녕 — Olá / Oi

한국 — Coreia

사람 — Pessoa

학교 — Escola

친구 — Amigo

사랑 — Amor

Leia cada bloco da esquerda para a direita e depois continue para o próximo bloco.
